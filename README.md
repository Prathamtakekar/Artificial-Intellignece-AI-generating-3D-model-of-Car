# Text-to-3D Model Generator using OpenAI Point-E

## Description
This prototype generates a 3D point cloud and exports it as `.obj` from a simple text prompt using OpenAI’s Point-E model.

## Prompt Used:
> "a small red toy car"

## Output
- A 3D model (.obj) viewable in any 3D tool
- Visualized using Plotly inside Colab

## How to Run
1. Open `PointE_Text_to_3D_Colab.ipynb` in Google Colab
2. Run all cells
3. Download the exported `.obj` model

## Libraries
- torch
- plotly
- OpenAI Point-E (from GitHub)
